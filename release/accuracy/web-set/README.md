# Frozen online endpoint dataset

Start with REPORT.md for results and manifest.json for original source URLs, source-group split and hashes. Canonical point annotations are in annotations/. The initial draft acquisition-05-points.json is retained as annotation history and is not used by the evaluator.

Original photographs and annotated visual previews are stored locally under output/web-annotation/ and excluded from Git. Model outputs are not annotation truth. The frozen v1 input and labels must not be silently changed; use a new version with review history for corrections.

This set has five independent photo groups: four product photos and one restaurant photo. It is not a population-accuracy claim, and unknown overlap with the model's original training data cannot be ruled out.
