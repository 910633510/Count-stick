本轮结论：自动区域没有新增已确认端面的漏检，但也没有补回原模型漏掉的端面。它只删掉了一个按冻结协议计为误检的边缘点；这个点紧贴不确定边界，收益需要谨慎解读。当前结果仍不足以支持不经人工核对直接结账。

验证日期：2026-10-23。两张新图片、两个独立来源组，共140个人工确认端面。图片、人工点位、匹配半径和忽略区域先经独立复核并冻结，随后冻结自动区域代码与OCR设置，再对每张图片运行一次全图CoreML推理。独立审计没有再次运行模型、OCR或区域选择器，也没有修改标签、代码或原始预测。
