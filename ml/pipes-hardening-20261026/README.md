# 圆钢管强化实验：未通过，不启用

本轮新增 69 个审核视图：21 个圆管正例（18 个场景组、100 个框），48 个非管材负例。负例中 32 个是未改动原像素的真实局部裁剪，仅用于训练；它们来自 7 个保守来源/直径池，不能说成 32 个独立现场。其余 16 个是完整工业照片。数据分为新训练 42、验证 7、封存测试 20；与原开发数据合并后训练 206、验证 47。

从原 pipe epoch20 初始化，训练 12 轮、实际消费 3,840 条样本；固定检查点 4/8/12、置信度 0.3、NMS 0.7。前 4 个网络模块及其 BN 冻结，采用旧正例/新正例/负例 50%/25%/25% 的分组采样。实际检查点、采样、数值和冻结状态检查通过；**训练顺利结束不等于模型合格**。

3 个候选全部未达到验证门槛，`selected=null`。第 12 轮是研究排序最好的候选，但仍失败：

| 旧 40 张验证图 | 原模型 | 第 12 轮 |
| --- | ---: | ---: |
| TP | 4,300 | 4,262 |
| FP | 152 | 129 |
| FN | 143 | 181 |
| 小于 16 像素目标 TP | 33 | 21 |
| 正例 WAPE | 3.31% | 3.80% |

新验证图中，8 个管口和 2 个管口的照片计数正确；MACO21 实际 17 个管口仍输出 0，Xincheng 实心棒材照片误报 18 个。两条 App 输入路径的实际像素和缓存一致；MACO21 的 GT 附近有几何候选，但匹配框置信度极低，Xincheng 的误框落在实际实心端面。没有发现图像、方向或坐标接线问题。

全部 282 个缓存、指标、门槛及 `selected=null` 已独立复算确认。**新 20 张测试图未进行模型推理**，旧 37 张失败集也未再次推理；没有转换、启用本轮模型，更没有上传新版 App。
