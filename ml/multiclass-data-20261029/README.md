## 菌落数据的关键检查

AGAR 下载的是官方代表样例包，**不是完整的 18,000 张数据集**。包内 40 个 JPEG 与 40 个 JSON 完整配对，压缩包全部成员 CRC、安全路径、提取字节和框坐标均已核验。

- 作者总目标数为 1862；全部类别框数为 1886，两者不能直接混用。
- 图片 734 含 54 个作者目标类别框和 24 个 `Contamination` 框。污染物可能涉及其他生长或非目标内容，不能未经明确规则把全部 78 个框合成通用菌落真值，也不能简单将另 24 个可见区域当背景。因此暂时整图隔离。
- 图片 1399 的作者数量为 `-1`，原图有大量生长，却没有穷尽实例标注；它是不可计数正例，**不是零菌落负例**，也暂时隔离。
- 剩余 38 对对应 1808 个目标框。类别包括酵母在内的菌落，不做物种识别或临床用途有效性声明。
- 这批样例 **没有真实空皿负例**。作者没有提供可靠物理皿 ID 或训练／验证／测试划分；尚未分组或创建新划分。

独立复核实际检查了大菌落、相接菌落、大小混合以及上述两个特殊样例的原图与框位置，支持坐标解释；这不是对所有 1808 个目标的专家重新标注。低对比与皿边的小目标仍需逐图审查。SP-SDS 的融合条带也不能强行分配实例数量。

来源：[AGAR 官方](https://agar.neurosys.com/)、[SP-SDS Mendeley v2](https://data.mendeley.com/datasets/f8ykr3bt7y/2)。[来源与访问结果](colony/source-summary.json) · [独立检查](colony/independent-audit.json) · [38 对候选索引](../../output/multiclass-data-20261029/colony/colony-candidate-index.json)。

## 签子数据的边界

本轮尚未找到能够匿名取得的大规模、带完整实例框的餐后签束端头数据集。大量搜索结果是烤盘整根肉串、侧视牙签、封闭包装、渲染图或已经用过的照片，已分别标记和排除。

7 张端面候选不等于 7 个已核实的餐厅拍摄场景。50 点参考图是木圆杆商品照片，逐排核对为 `3+6+8+8+8+7+6+4=50`；它只有中心点，不能自动当成 50 个检测框。商品包装或宣传文字中的“100 支”也没有用作照片真值。

经典特征与普通／镜像比对覆盖 45 个已有发布／采集身份和 33 张本轮候选。发现的新 GitHub 展示图实际上与原来的留出场景同源，另一个 Commons 文件与已有发布素材同源，均已排除。没有把旧 11 个冻结场景挪进训练集。来源／拍摄分组仍然是保守关系，不能据此证明所有照片物理独立。

来源追溯、每张图用途与排除原因见[签子候选清单](../../output/multiclass-data-20261029/skewers/source-catalog.json)；[QA](skewers/qa-summary.json) · [50 点独立核对](skewers/root-point-review.json)。
